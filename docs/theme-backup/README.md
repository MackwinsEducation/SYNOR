# Theme backup

The live theme's original `templates/blog.json` and `templates/article.json`,
taken before the blog layer replaced them.

Both were stock Dawn — `main-blog` and `main-article` with default settings.
Nothing in them was custom, so nothing was lost. They are kept here only so
there is a way back that does not depend on remembering what Dawn shipped.

Taken from **SYNOR work copy 4** (the live theme) on 15 September 2026.

To restore, put either file back at its original path in the theme.
